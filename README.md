# VE Bank Windhoek Gateway

Bank Windhoek (via Adumo) payment gateway for Venture Events plugin.

## Features
- Test Mode with official Adumo staging credentials (3DS by default)
- Automatic JWT generation
- Hosted payment page
- Return URL handling

## Setup
1. Activate the plugin.
2. Go to **Events → Bank Windhoek Settings**.
3. Configure your credentials.
4. Enable Test Mode for development.

## Notes
- Uses gateway ID `adumo` internally (for compatibility).
- Bank Windhoek requires 3D Secure in most cases.
